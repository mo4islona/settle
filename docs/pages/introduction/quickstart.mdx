# Quickstart [Calculate a live table and see Settle correct it after a fork]

<LanguageSwitch label="Code language" />

In this example, your app keeps the trade volume of each pool. You send two blocks to Settle. Then the chain replaces one block, and you see how Settle corrects the volume.

Use the switch above to show the code in TypeScript or in Rust. The choice applies to all pages.

::::steps

### Create a project

:::code-group

```bash [TypeScript]
mkdir settle-quickstart
cd settle-quickstart
npm init -y
npm pkg set type=module
npm install @settle/stream
npm install --save-dev tsx
```

```bash [Rust]
cargo new settle-quickstart
cd settle-quickstart
cargo add settle --git https://github.com/mo4islona/settle
```

:::

For TypeScript, you need Node.js 18 or later. Write the code of the next steps into `index.ts`. For Rust, write it into `src/main.rs`.

## What happened

1. The first two blocks gave one row for each pool.
2. The chain replaced block 2. Settle found the last block that the two chains have in common: block 1. It removed the effect of the old block 2: the ETH/USDC volume went back to 100, and the BTC/USDC row went away.
3. The new block 2 added 300 to the volume of ETH/USDC.

You did not write code for the fork. The same `apply` function wrote all changes.
